樹懶法師的自動化工房

S L O T H   F A C T O R Y

樹懶法師的第一信條：能讓機器做的事，絕不自己動手。
從一台挖礦機開始，鋪輸送帶、蓋熔爐、組裝魔導元件， 最後讓整座工房自己生產出「終極樹懶符文」——而你只要看著就好。

  • 左鍵 放置建築（在礦上點擊可手動挖礦）
  • 右鍵 或 X 拆除　R 旋轉方向
  • 1–8 選建築　Esc 取消選取
  • 拖曳中鍵/空白 或 WASD 移動視角　滾輪 縮放
  • 點擊已放置的機器可設定配方

提示：機器會自動從相鄰的輸送帶取料，並把成品吐到自己面向的那格。 輸送帶的方向就是它的箭頭方向。
